# Future cognition boundary

The policy boundary is `AgentPolicy.decide(Observation) -> AgentIntent`. Observations are independent copies containing self physiology/inventory, visible terrain, visible resources and occupied positions. The policy never receives the mutable world or the engine. AgentIntent proposes movement, survival, social, storage, crafting or construction actions and optional explained goal metadata; the authoritative resolver validates it at execution time.

An asynchronous LLM policy should be scheduled outside the synchronous engine. The service can publish observations to a bounded cognition task, keyed by run ID, agent ID and observation tick. Results enter a FIFO command/intent mailbox with those identifiers. At a tick boundary, the writer rejects results for old runs, dead actors, expired observations or unsupported actions, then applies the normal validator against current state. Missing/late/malformed proposals use a documented deterministic fallback (rule policy or IDLE); inference must never block the world clock or mutate world state.

Record accepted cognition proposals and their consumption tick in events before applying them. LLM output is not inherently deterministic: reproducible experiments must replay recorded proposals, not call the model again. Existing mutation-event replay already works independently of any policy.

A later phase can add Ollama, structured JSON validation and a bounded scheduler. Phase 2 already supplies normalized personalities, bounded resource/chunk knowledge, proximity relationships and explained utility candidates. These are a deterministic fallback and debugging boundary, not language-model cognition or episodic/semantic memory. Future memory summaries and beliefs can enrich copied observations without replacing physical authority. Trade, dialogue, richer relationships and multi-settlement negotiation require new deterministic validators/resolvers and reducer events. There is no LLM client or distributed queue in this implementation.
